# 큰글씨 돋보기 — 확대·손전등

앱 패키지: `com.barolab.biglens`. Android 8 이상, target API 36. 아직 제작·검증 중이며 다운로드 수·수익·실사용 성공률은 미측정이다.

## 누구의 어떤 일을 돕는가

50~70대 사용자가 상품 라벨, 식당 메뉴, 영수증 등의 작은 글씨를 잠깐 크게 보는 상황이 가설이다. 시력 치료·약품 식별·판독 정확도를 보장하지 않는다. 최초 실행부터 확대 조작까지 막는 광고를 없애고, 정지한 화면을 손 떨림 없이 살펴보는 데 집중한다. 경쟁 우위와 수요는 실제 사용자 테스트로 확인해야 한다.

## 화면과 흐름

1. 첫 화면에서 카메라 필요 이유와 자동 저장·업로드하지 않는다는 설명을 제공한다. 허용은 사용자가 선택한다. 거절 후 재시도·앱 권한 설정·사용 안내가 남는다.
2. 실시간 화면: 검정·네이비 바탕과 호박색 주요 버튼. 실제 CameraX 최소·최대 배율을 보여주고 해당 범위 안의 1/2/4/8배 프리셋만 제공한다. 모든 기기의 10배 확대를 약속하지 않는다.
3. 화면 정지: 현재 보이는 미리보기 장면을 메모리 비트맵으로 잡고 카메라·조명을 해제한다. 고대비와 원본을 비교하고 사용자가 선택한 때만 PNG를 저장한다. 카메라 원본 고해상도 촬영이나 OCR 기능은 아니다.
4. 다시 실시간 보기: 정지 화면을 지우고 카메라를 연결한다. 앱을 벗어나면 카메라와 조명을 해제한다. 회전 때 정지 비트맵은 메모리로 전달하지만 프로세스 종료 후 보존을 약속하지 않는다.
5. 사용 안내: 거리·초점·조명 미지원·발열·권한·저장 위치에 대한 설명. 도움말 하단 배너는 별도 사용자 선택이며 핵심 돋보기에는 광고가 없다.

가로에서는 카메라와 조작부를 좌우로 배치하고 조작부와 권한 안내를 스크롤할 수 있다. 터치 버튼은 최소 52dp, 색상뿐 아니라 ‘켜기/끄기’와 상태 글자로 구분한다. 저장은 시스템 문서 선택기를 이용해 파일·미디어 전체 권한을 요구하지 않는다. 저장된 장면의 긴 변은 최대 2048픽셀이며 고대비 선택 상태가 출력 PNG에 반영된다.

## 기술 범위와 근거

0.2.0 소스에서는 화면 탭/초점 버튼, 정지 사진의 확대·이동·원래 크기 복귀, 원본/고대비/흑백 반전을 추가했다. 정지 사진 배율은 카메라의 광학·디지털 배율과 구분한다. 저장은 이동·확대한 화면의 잘라낸 부분이 아니라 선택 색상이 반영된 사진 전체이며 버튼에도 ‘사진 전체 저장’으로 표시한다. 회전 시 메모리 사진의 보기 위치를 전달한다. 이 문장은 구현 범위이며 실제 카메라 기기·통합 QA·출시 성공을 뜻하지 않는다.

CameraX **1.6.2 안정 버전**의 camera-camera2/core/lifecycle/view, AndroidX ComponentActivity LifecycleOwner를 사용한다. PreviewView COMPATIBLE 모드와 실제 스트림 준비 상태를 확인한 뒤 정지한다. 사진 촬영 UseCase를 별도로 연결하지 않아 미리보기와 촬영 화각 차이를 피한다. 콜백은 세션 번호와 활성 상태로 검사하고 닫힌 카메라의 확대·조명 결과를 현재 화면 성공으로 표시하지 않는다.

- [CameraX 공식 안정 버전](https://developer.android.com/jetpack/androidx/releases/camera)
- [PreviewView 미리보기](https://developer.android.com/media/camera/camerax/preview)
- [기기별 확대·조명과 lifecycle 동작](https://developer.android.com/media/camera/camerax/configuration)

이전 앱의 서식을 복사하지 않고 영상 중심 분할 화면을 사용한다. OCR·AI·계정·영상 업로드·사진첩 일괄 접근·자동 촬영·상시 백그라운드 카메라·의료 판독은 제외한다.

## 광고와 개인정보

확대, 조명, 화면 정지·해제, 저장 버튼에 전면·보상형 광고를 넣지 않는다. 도움말에서 명시적으로 선택한 배너만 공통 동의 래퍼를 거친다. 비맞춤 광고도 Google SDK의 기기·IP·상호작용·진단 데이터 처리가 있을 수 있다. 카메라 원본과 정지 이미지·파일 URI는 광고 매개변수로 전달하지 않는다. 자체 분석 SDK는 없다. 저장 제공자가 클라우드인 경우 사용자 선택과 제공자 정책이 적용되며 앱의 자동 업로드와 구별한다.

## 검증과 출시 기준

자동 검증: 실제 최대 2배 기기에서 8배 요청이 2배로 제한됨, 0.5배 등 하한, 배율 고정 기기, NaN 값, 슬라이더 양 끝·왕복 값. SDK 26 호환 lint와 manifest의 카메라·조명 optional feature를 확인한다.

실행 검증: 권한 허용/거절/반복 거절 후 설정 복귀, 후면 카메라 없음, flash 없음, 실제 하드웨어 배율, 스트림 전 정지 비활성, 빠른 정지/해제, 조명 켠 채 앱 전환·회전·사용 안내 진입 시 해제, 가로·큰 시스템 글씨, 정지 고대비, 저장 성공·사용자 취소·저장 제공자 거절, 프로세스 종료 후 상태를 시험한다. 에뮬레이터 영상 성공은 실휴대폰 초점·조명·열·배터리 검증을 대신하지 않는다. 제한 사항은 QA 영수증에 남긴다.

공개 출시 전 실제 앱 전용 광고 ID·UMP·개인정보 웹 문서·데이터 보안·스토어 이미지·테스트 요건·Play 심사를 확인한다. 앱에 대한 의료적 효능을 주장하지 않는다. 정식 광고 동작과 수익 측정은 별도 단계이다.

## 출시 후 측정

실제 사용자에게 ‘작은 글씨를 찾고 멈춰서 저장’ 과제를 주고 완료 여부, 권한에서 막힌 이유, 읽기 편한 거리와 조작 실수를 직접 기록한다. 첫 주 재사용과 불편 의견을 Play/테스터 피드백으로 관찰한다. 광고는 도움말 선택 배너의 실제 노출·수익·eCPM을 AdMob에서 수집한 후 비용과 함께 본다. 다운로드·활성 사용자·매출은 연결 전 `null/미수집`이며 가상의 0이나 수익 예측을 성과로 표시하지 않는다.
