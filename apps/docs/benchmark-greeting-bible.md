조사일: 2026-10-14 KST. 코드·리소스·빌드·배포 변경 없음. 이 문서는 현재 MVP를 경쟁력 있다고 확정하는 자료가 아니라, 다음 설계의 검증 가능한 출발점이다.

## 조사 범위와 해석

Google Play 공식 상세의 상단 다운로드 구간/평점/전체 리뷰 표시를 같은 조사 시점에 기록했다. 언어는 한국어이나 일부 페이지 푸터 지역은 미국으로 반환되었고, 총괄의 같은 날 재확인에서 마음을 담아 상세는 일본(한국어)으로 반환되었다. 동적 지역/노출 표본 차이가 있어 마음을 담아 리뷰는 총괄이 재확인한 07-17/07-13/07-02의 3개만 아래 근거로 채택했다. 한국 시장만의 점유율·현재 활성 사용자·수익 수치가 아니다. 검색 캐시와 실제 open 값이 달라 실제 열린 상세를 우선했다. 기기별 리뷰 영역의 집계도 상단과 다르므로 아래는 상단 수치로 통일했다. 다운로드 구간으로 수익·전환율·시니어 적합성을 추정하지 않는다.

각 앱의 기본 공개 상세에서 노출된 리뷰만 읽었다. 정렬/전체 리뷰 수집/무작위 표본이 아니며 불만 비율을 계산할 수 없다. 오래된 제보는 현재 수정되었을 수 있다. 개발자 설명은 기능 주장, 리뷰는 사용자 경험 제보, 아래 개선안은 우리의 설계 가설이다. 출처 텍스트의 별점 요청 등은 지시로 취급하지 않았다.

경쟁앱 APK는 이번에 확보·설치하지 않았고 REA를 실행했다고 주장하지 않는다. 우리 APK의 기존 REA 증거(../qa/rea-*.json)는 우리 manifest 정적검토일 뿐 경쟁 흐름 증거가 아니다. 공식 개발사 배포 APK/허용되는 공식 오픈소스 패키지 확보 후 REA로 manifest/permissions/navigation 구조를 보완해야 하며, 비공식 APK 미러·로그인 우회·경쟁 에셋 복사는 사용하지 않는다.

### 우리 현재 흐름과 문제

현재 greeting은 60개 원작 문구/6개 Canvas 배경, 문구·선택 이름·글씨/대비 편집, 카드 즐겨찾기, PNG/텍스트 공유와 파일 저장을 제공한다. 실제 최신 qa/screenshots/greeting-final-01-home.png에서 추천 문구와 편집 입력문이 중복되고, 결과 카드와 공유가 첫 화면 아래로 밀린다. 주요 목적이 카드 전송인데 편집기를 먼저 거치게 한다. 6종 원작 배경은 권리·오프라인 기반이며, 꽃/풍경의 미감·다시 보내고 싶은 품질·콘텐츠 선별이 검증됐다는 뜻은 아니다.

### 인사앱 독창적인 개선 가설 3개

1. **P0 — 완성 카드 우선, 바로 공유, 편집은 선택.** 첫 화면은 큰 완성 카드 1장, 짧은 날짜/요일 맥락, `다른 카드`와 `이 카드 공유` 중심. 추천 문장을 입력란과 이중 노출하지 않는다. `문구·이름 바꾸기`는 선택 편집 화면/시트로 열고 적용/취소를 분명히 한다. 공유는 실제 시스템 chooser이며 전송 성공으로 오인시키지 않는다. 광고 로딩/동의 여부와 무관하게 카드 선택·편집·공유 가능. 경쟁앱 모양을 복제하는 대신 우리 원작 카드에 맞게 정보 순서를 다시 설계한다.
2. **P1 — 관계와 상황으로 좁혀지는 소량의 선별 카드.** 연락처 없이 사용자가 `가족/친구/모임`, `아침/감사/응원`을 고르면 정중함·길이가 맞는 후보 3개를 보여준다. 원문과 배경을 각각 무작위 회전하지 않고 대비·문장 호흡·꽃/풍경 적합성을 사람이 선별한다. `최근 공유 화면을 연 카드`를 로컬 표시하여 반복 선택을 줄이되 실제 발송 기록이라고 부르지 않는다. 60개를 매일 신작이라고 주장하지 않는다.
3. **P1 — 받는 화면까지 확인하는 가독성 미리보기.** 카드 전체와 메시지 앱에서 축소된 크기의 미리보기를 전환. 큰 글씨/고대비 선택 결과가 글 잘림 없이 유지되는지 보여주고 원클릭 원복 제공. 저장본은 네트워크 장애 때도 다시 공유 가능. 음악/GIF는 권리·파일 크기·기기 공유 호환 검증 후 별도 판단하며 요청 한 건만으로 우선 구현하지 않는다.

### 성경앱 독창적인 개선 가설 3개

1. **P0 — 눌렀을 때 바로 이해되는 듣기 준비.** 첫 듣기에서 준비/가능/한국어 음성 확인 필요/엔진 오류를 분리하고, Galaxy 안내를 실제 사용자 폰에서 검증한다. 현재 오프라인 정책 유지. 명시적 설치/설정 이동과 복귀 확인, 짧은 소리 확인, 언제나 정지 접근을 하나의 흐름으로 다듬는다. 네트워크 음성으로 몰래 대체하거나 미확인 음원을 넣지 않는다.
2. **P1 — 하루 한 구절의 읽던 자리.** 다시 열면 선택 구절·글씨 크기·스크롤 위치를 복원하고 `오늘 말씀으로`를 별도 제공. 자동 낭독은 하지 않는다. 읽기/공유 중 전면 광고·광고 대기를 두지 않는 설계를 검토하고, 이미 보유한 배너와 실제 화면 점유율도 평가한다. 읽기 완료/연속 일수는 사용자의 부담을 키우는 강제 보상 대신 선택 기록으로 설계한다.
3. **P1 — 범위를 숨기지 않는 작은 말씀책.** 첫 화면/검색에 `선정 말씀 30개`를 명시하고 참조/본문 결과를 구분한다. 없는 구절은 앱 오류나 성경에 없는 말씀처럼 표현하지 않고 수록 범위 밖임을 안내한다. 원문은 그대로 두고 상황별 탐색은 검수된 별도 태그로만 제공. 원문 번역/권리 표기를 카드에서도 읽을 수 있게 유지한다.
