# 오늘의 안부 — 인사말 카드·공유 V1 기획

## 사용자가 얻는 것
50~60대가 가족·지인에게 보낼 짧은 안부를 직접 고르고 고쳐 이미지 또는 글로 전달한다. 첫 화면에서 추천을 보고, 카드에 내 말을 보태고, 기기의 공유 화면으로 넘기는 세 단계가 중심이다. 가입·연락처 접근·받는 이 자동 지정·카카오톡 자동 발송은 없다. 성경 앱과 별도 제품/패키지 `com.barolab.morningcard`다.

## 주요 흐름과 실제 범위
1. **오늘 안부**: 기기 날짜/요일과 완성 카드 한 장을 보여 준다. 초안이 없을 때 날짜에 따른 문구를 초기값으로 사용하며 저장된 초안을 덮어쓰지 않는다. ‘다른 카드’에서 관계·상황을 선택하고 기존 문구 후보 3개 중 고른 때만 문구를 바꾼다. 날씨·기온·위치·받는 이의 상태를 감지하지 않는다.
2. **편집**: 300자까지 직접 수정한다. 보내는이 이름은 20자 선택 입력이고 표시 스위치는 처음 꺼져 있다. 이름을 안 넣어도 모든 공유 기능을 쓸 수 있다. 작성중 문구·이름·배경·글씨·대비는 로컬에 남는다.
3. **꾸미기**: 기존 Canvas 기하 그림 여섯 가지에 원작 사진 꽃·바다·가을 세 가지를 더한다. 타사 카드·명화·사진·유료 폰트 에셋을 복사하지 않는다. 초기 사진 선택은 월만 이용하며 사용자가 바꿀 수 있고 기존 저장 테마 ID는 유지한다. 카드 글씨 52/64/76px, 흰 바탕 고대비를 제공한다. 긴 글은 가변 높이를 사용하며 극단적인 줄바꿈과 최대 크기 안전성은 별도 QA 항목이다.
4. **전달/저장**: 카드 이미지 공유와 글로 공유는 Android 공유 시트를 연다. 받는 앱과 상대는 사용자가 정한다. 이미지 저장은 시스템 문서 저장 위치 선택(SAF)을 연다. 공유 완료 여부나 상대방 열람을 앱이 추적·보장하지 않는다. 카카오톡 설치를 요구하지 않으며 공유 전 광고를 요구하지 않는다.
5. **다시 쓰기**: 문구 모음에서 수동 검토한 원작 60개를 7개 카테고리로 고른다. 내 카드에는 문구·선택 이름·배경·글씨·대비 스냅샷을 보관하며, 다시 꾸미기·개별 삭제·전체 삭제를 제공한다.

## 디자인 원칙
크림색 배경, 짙은 녹색 글씨, 최소 52dp 버튼, 시스템 글자 확대 대응을 기본으로 한다. 홈/문구 모음/내 카드 세 메뉴만 노출한다. 카드의 흰 중앙 글판은 장식과 글씨를 분리한다. 장식은 모서리/상하단에 두며 실제 6개 원본 PNG로 겹침을 검수한다. 작은 가로 화면에서는 큰 장식 제목을 숨기고 본문 전체 스크롤을 확보한다. 명언 인용이나 질환 치료·건강 호전·재물 운수 보장 문구는 넣지 않는다.

## 광고 면과 개인정보
내부/디버그는 Google 공식 테스트 광고만 사용한다. 문구 모음과 내 카드 목록에만 선택 배너 공간을 두며, 홈 카드 편집/미리보기/공유/저장 화면에는 외부 광고 호스트를 숨긴다. 전면·보상형·공유 전 강제 광고는 없다. UMP 동의·광고 로딩·광고 미수신은 문구 편집/공유와 독립적이다. 광고가 없어도 기본 기능을 모두 쓸 수 있다. 이름·문구·즐겨찾기·카메라/연락처/위치 데이터를 광고 요청에 넣지 않는다.

별도 서버·분석/크래시 SDK·회원 계정은 없다. Google 광고·동의 SDK의 처리 항목은 개인정보 페이지에 별도 공개한다. 앱 데이터 백업은 끄고 cloud/device transfer에도 로컬 자료를 제외한다. 공유 PNG는 내부 캐시에 쓰고 24시간 넘은 파일은 다음 공유 때 정리한다(정시 자동 삭제 보장 아님). 사용자가 SAF로 저장한 PNG는 앱 제거 후에도 남을 수 있다. 앱 내부 즐겨찾기 삭제 또는 Android 앱 데이터 삭제/제거로 로컬 초안·이름·설정을 지울 수 있다. 지원 `baro76650@gmail.com`; 개인정보 URL은 `https://barolab-daily-apps.pages.dev/greeting/privacy`이며 실제 배포 확인은 별도 증거로 관리한다.

## 리텐션/수익 가설과 검증
가설은 ‘요일별 추천으로 다시 방문할 이유가 생긴다’, ‘내가 고친 문구와 저장 카드가 재사용을 돕는다’이다. 검증 전 사실처럼 홍보하지 않는다. 이미지의 작은 앱 이름은 출처 표시이며 설치 유입이나 바이럴을 보장하지 않는다. 깨진 Play 링크/QR을 넣지 않는다. 공유량·가족 관계·개인 메시지를 몰래 수집하지 않는다.

첫 수익 측정은 Play/AdMob 콘솔의 실제 이용자·광고 노출·eCPM·수익을 기간/조회시점과 함께 기록한다. 아직 실광고 ID/측정 연결이 없으므로 수익/DAU는 null이며 테스트 광고를 수익으로 계산하지 않는다. 운영비를 별도 집계한 순수익과 재사용 의견이 우선이다. 제한된 실제 사용성 테스트로 글씨·문구 자연스러움·공유 절차를 평가하고, 추가 계측을 넣을 때는 동의·정책·최소 수집 설계를 별도 검토한다.

## QA와 출시 게이트
- 콘텐츠: 60개 이상, ID/문구 중복·누락 없음, 카테고리 7개 채움, 직접 고칠 수 있는 300자 한계 내. API 후보를 수동 검토했고 유명인 인용/가사/외부 카드 복제는 사용하지 않았다.
- 실제 런타임: 오늘 추천, 카테고리 변경, 글 수정/선택 이름, 6개 배경/고대비/글씨 크기, 긴 글 PNG 끝까지 표시, 즐겨찾기 재시작 보존/삭제, 이미지·글 공유 시트, SAF 저장·취소, 회전과 시스템 글씨 확대/가로 높이를 확인한다. 개인에게 실제 메시지를 보내지 않는다.
- 보안/정책: 최소 권한, provider 외부 비공개+읽기 URI만 일시 허용, 서버로 개인 입력을 보내지 않음, UMP 비동기 파괴 상태/동의 변경 후 광고 재요청, 광고 없이 공유 가능을 확인한다.
- 빌드: min26/target36, Android lint/단위 테스트, 지속 업로드 키 서명, 실제 APK 정적 REA 검증 및 에뮬레이터 QA를 별도 기록한다. 정적 분석만으로 실제 기능 성공을 단정하지 않는다.
- 배포: 내부 테스트 AAB는 실제 패키지+테스트 광고+preview 표시이며 공개 프로덕션으로 승급하지 않는다. 앱별 실제 신규 AdMob ID와 콘텐츠/개인정보/광고 검토가 없으면 release 빌드는 차단한다. Play 목록/개인정보/성인 대상/광고·데이터 안전/실제 스크린샷 및 필요한 비공개 테스트·검토를 완료한 뒤 별도 정식 빌드를 준비한다.

## 후속 범위
사진 업로드·예약 자동 발송·메신저 전용 SDK·연락처 동기화·대화 상대 추적·유료 글꼴·현재 날씨 API·생성형 무제한 문구/이미지·강제 로그인은 V1에 포함하지 않는다. 사용자 반응 없이 광고 종류나 기능 수를 늘리지 않는다.


## 0.2.0 재설계 구현과 내부 기술 QA

첫 화면은 날짜/완성 카드 한 장/`이 카드 공유`가 중심이며 추천 본문과 편집 입력을 중복 노출하지 않는다. `다른 카드`는 관계·상황 선택 후 사람이 검토한 기존 문구 순서의 후보3개로 좁힌다. 관계 선택이 실제 수신자나 연락처 수집을 뜻하지 않으며, 문구는 사용자가 직접 판단한다. 미리보기 축소/확대 확인, 내 카드 보관, 파일 저장/텍스트 공유는 선택 조작으로 남긴다.

편집은 별도 화면에서 문구·선택 이름·배경·글씨/대비를 바꾼다. 편집 전 상태와 편집중 상태를 구분하여 적용 전에 SharedPreferences 원본을 변경하지 않는다. 취소/뒤로는 확인 후 원래 카드, 회전은 두 상태를 SavedInstanceState에 보존한다. 내 카드의 동일한 전체 snapshot 재추가는 막고 서로 다른 디자인/이름 버전은 별개 카드로 허용한다. SAF pendingSave는 요청 당시 snapshot을 계속 독립 보관한다.

도형 테마0~5는 기존 즐겨찾기 의미를 유지한다. 새 원작 사진6꽃/7바다/8가을은 초기 사진 배경이며 기존 theme값은 덮어쓰지 않는다. 출처/프롬프트는 card-assets.md를 따른다. 1080px export에 사진 RGB565 decode→그리기→즉시recycle하며 본문은 가변 높이/부분 반투명 여백으로 보호한다. 사진 미감과300자/선택이름 잘림은 실제 렌더 QA 후에만 통과 표시한다. 사진이 있다는 사실은 실제50~70대 선호 검증과 다르다.
