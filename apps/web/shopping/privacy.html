목록명·항목명·수량·체크 상태·보관/템플릿·마지막 한 단계 복원 데이터와 글씨 설정을 기기에 저장합니다. 앱 서버·회원가입·클라우드 동기화는 없고 항목을 광고 요청에 넣지 않습니다. 미확정 입력과 미리보기는 회전 중 화면 상태로 유지하며 앱 종료·기기 재시작 후 복구를 보장하지 않습니다.

계정 가입과 별도의 앱 사용 분석·크래시 분석 SDK는 없습니다. 자체 측정 백엔드도 없습니다. 기기 백업·기기 이전에는 앱 데이터를 포함하지 않도록 설정합니다. 운영자가 앱의 로컬 내용을 원격 조회하지 않습니다.

2. 권한과 기기·외부 제공자

마이크는 사용자가 음성 입력을 선택할 때 RECORD_AUDIO 권한을 요청합니다. 거부해도 키보드 입력을 사용할 수 있습니다. 지원되는 기기에서는 Android 온디바이스 음성 인식을 사용하며, 한국어 모델이 없거나 오류가 나면 네트워크 방식으로 자동 전환하지 않습니다. 온디바이스가 없으면 매회 서버 전송·네트워크 사용 가능성을 설명하고 사용자가 이번 음성 사용을 선택한 뒤 Android 음성 제공자를 사용합니다. 제공자가 음성을 처리·보관할 수 있으므로 그 제공자의 정책이 적용됩니다. 앱 자체는 녹음 파일을 저장하지 않습니다. 끝내기·취소·백그라운드·회전 시 세션을 정리합니다.

3. 공유·저장

인식 결과는 바로 목록에 추가하지 않습니다. 사용자가 수정·분리 미리보기를 확인한 뒤 추가합니다. 수량이나 비슷한 이름을 임의 추측해 합치지 않습니다. 텍스트 공유를 선택하면 Android 공유 선택기를 통해 사용자가 고른 앱으로 목록을 전달합니다. 자동 전송이나 받는 사람 조회는 없습니다.

4. 광고와 동의 SDK

광고는 목록 개요 하단 배너만 사용합니다. 항목 체크·음성·입력 미리보기·공유 중 광고를 표시하지 않습니다. 현재 내부 테스트는 Google 테스트 광고를 사용하며 정식 광고는 아직 가동하지 않습니다.

Google Mobile Ads SDK와 User Messaging Platform(UMP)을 사용합니다. 비맞춤 광고를 요청하며 필요한 지역의 동의 절차와 광고 요청 가능 여부를 확인합니다. 광고 개인정보 선택 양식이 필요한 경우 앱의 광고 개인정보 선택에서 다시 열 수 있습니다. 동의·광고 처리가 실패해도 핵심 기능을 사용할 수 있습니다.

NPA(비맞춤 광고) 요청은 데이터 수집이 없다는 뜻이 아닙니다. Google SDK는 IP 주소와 이를 통한 대략적 위치, 기기 또는 기타 식별자, 앱·광고 상호작용, 진단·성능 정보를 광고 제공·측정·부정 이용 방지 등을 위해 수집·공유할 수 있습니다. SDK 전송은 TLS 보호를 따릅니다. 현재 테스트 광고와 정식 광고 구성은 구분합니다.

카드 문구·보내는 이 이름·장보기 항목·카메라 영상·음성 내용을 광고 요청 매개변수·관심 분류·콘텐츠 URL로 넣지 않습니다. 광고 SDK의 보관·삭제는 Google의 정책과 기기 설정에 따르며 운영자가 Google 기록을 일괄 삭제한다고 보장하지 않습니다.
