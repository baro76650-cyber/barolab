주요 기능

  • 문구와 보내는 이 이름을 직접 확인하고 수정
  • 테마·글씨·대비를 바꾸고 미리보기
  • 즐겨찾기와 사용자 선택 이미지 저장·공유
  • 관계·상황에 맞는 문구 후보 3개에서 고르기
  • 별도 편집 화면에서 수정한 뒤 적용 또는 취소
  • 기존 도형 배경 6가지와 새 원작 사진 배경 3가지
  • 기존 저장 카드의 배경 선택을 유지하는 즐겨찾기

사용 전에 확인해 주세요
