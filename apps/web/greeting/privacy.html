1. 기기에서 처리하는 정보

직접 입력한 문구(최대 300자), 선택 입력한 보내는 이 이름(최대 20자), 이름 표시 여부, 테마·글씨·대비·작성 중 초안과 즐겨찾기 스냅샷을 기기에 보관합니다. 보내는 이 이름 표시는 기본 꺼져 있으며 사용자가 선택합니다. 연락처·마이크·카메라 권한이나 자동 발송 기능은 없습니다.

계정 가입과 별도의 앱 사용 분석·크래시 분석 SDK는 없습니다. 자체 측정 백엔드도 없습니다. 기기 백업·기기 이전에는 앱 데이터를 포함하지 않도록 설정합니다. 운영자가 앱의 로컬 내용을 원격 조회하지 않습니다.

2. 권한과 기기·외부 제공자

입력한 이름이나 문구를 앱 서버로 전송하거나 생성 모델에 보내지 않습니다. 회원가입과 연락처 조회 없이 사용합니다.

3. 공유·저장

카드 PNG 공유 시 앱 캐시의 shared 폴더에 임시 파일을 만들고 선택한 공유 앱에 임시 읽기 권한을 줍니다. 생성 후 24시간이 지난 공유 파일은 다음 공유 때 정리합니다. 정확히 24시간 후 자동 삭제하는 방식은 아닙니다. 저장 버튼은 Android 문서 선택 화면에서 사용자가 위치를 고릅니다. 클라우드 위치를 고르면 해당 제공자의 처리가 적용되며 앱 제거 후에도 선택한 저장 파일과 다른 앱의 공유 사본은 남을 수 있습니다.

4. 광고와 동의 SDK

카드 편집·미리보기·공유·저장 화면에는 광고를 표시하지 않습니다. 문구 모음과 내 카드 목록 하단에서만 배너를 허용하며 전면·보상형 광고는 없습니다. 현재는 Google 테스트 광고를 사용하며 정식 광고는 아직 가동하지 않습니다.

Google Mobile Ads SDK와 User Messaging Platform(UMP)을 사용합니다. 비맞춤 광고를 요청하며 필요한 지역의 동의 절차와 광고 요청 가능 여부를 확인합니다. 광고 개인정보 선택 양식이 필요한 경우 앱의 광고 개인정보 선택에서 다시 열 수 있습니다. 동의·광고 처리가 실패해도 핵심 기능을 사용할 수 있습니다.

NPA(비맞춤 광고) 요청은 데이터 수집이 없다는 뜻이 아닙니다. Google SDK는 IP 주소와 이를 통한 대략적 위치, 기기 또는 기타 식별자, 앱·광고 상호작용, 진단·성능 정보를 광고 제공·측정·부정 이용 방지 등을 위해 수집·공유할 수 있습니다. SDK 전송은 TLS 보호를 따릅니다. 현재 테스트 광고와 정식 광고 구성은 구분합니다.

카드 문구·보내는 이 이름·장보기 항목·카메라 영상·음성 내용을 광고 요청 매개변수·관심 분류·콘텐츠 URL로 넣지 않습니다. 광고 SDK의 보관·삭제는 Google의 정책과 기기 설정에 따르며 운영자가 Google 기록을 일괄 삭제한다고 보장하지 않습니다.

  • Google SDK 데이터 공개
  • Google 개인정보처리방침
  • Google 광고 기술 안내
