# 하루말씀 스토어 등록 이미지

- `store-icon-512.png`: 512×512, 32비트 RGBA PNG, Google Play 앱 아이콘용
- `feature-graphic-1024x500.png`: 1024×500, 24비트 RGB PNG, 알파 없음, 그래픽 이미지용
- 같은 이름의 SVG는 원본입니다. 기존 앱의 책 벡터를 확장한 자체 도안이며 유료 이미지·사진·폰트 파일을 추가하지 않았습니다.

큰 글씨 문구와 30개 구절 순환이라는 사실을 유지했습니다. 실제 앱 화면처럼 보이는 가짜 목업은 넣지 않았습니다. 두 PNG를 직접 열어 한글 표시와 잘림·겹침을 확인했고, 초록·크림 색상 명암비는 7.138입니다. SVG는 시스템 폰트를 참조하며 PNG는 설치된 맑은 고딕으로 출력했습니다. 폰트 바이너리는 포함하지 않습니다.

실제 앱 스크린샷 원본은 `../qa/screenshots/01-today.png`, `02-favorites.png`입니다. API 36 에뮬레이터에서 촬영한 실제 화면이며 꾸미거나 수정하지 않았습니다. 현재 개발 미리보기와 Google 테스트 광고 표시가 있으므로 프로덕션 출시 화면이라고 소개하지 않습니다. 최종 스토어 제출 시 사용할 실제 빌드와 일치하는지 등록 담당자가 검토합니다. 필요하면 앱 담당자가 실제 빌드를 다시 촬영하며, 표시를 이미지 편집으로 지우지 않습니다.

추가 실제 화면은 `05-settings.png`와 `07-device-share-sheet.png`입니다. 권한 요청·거절 및 음성 미설치 안내 화면은 QA 증거로 구분합니다. 공유 시트 촬영은 실제 PNG 카드 미리보기를 확인한 것이며 다른 사람에게 전송하지 않았습니다.

치수·PNG 형식·해시·실제 스크린샷 원천은 `asset-manifest.json`에 기록했습니다. 앱 코드·기존 원본 벡터·QA 스크린샷은 수정하지 않았습니다.
