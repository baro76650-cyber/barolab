# 본문 출처·권리와 출시 인계

확인일: 2026-10-14. 이 팩은 30일 동안 하루 한 절을 보여주기 위한 원문 데이터다. 성경 본문은 AI가 작성하지 않았다. 실제 eBible 배포 파일에서 절별 문자열을 추출했고, 선정한 30개 모두 동일 제공자의 장별 HTML과 대조했다. 공백만 정규화하여 비교했으며 저장 본문은 VPL 원문을 그대로 유지했다. 시편23:1의 표제, 옛 철자·띄어쓰기·구두점도 임의로 고치지 않았다.

## 선택한 판본과 재사용 근거

[eBible 판본 정보](https://ebible.org/bible/details.php?all=1&id=kor)와 ZIP 내부 about 문서는 이 자료를 `The Holy Bible in Korean, 1910 translation`, `KOROLD / kor`, `Public Domain`으로 표시한다. 앱에도 이 제공자 표기를 사용한다. 기여자 표기는 레널즈·이승두·김정삼이다. 이를 개역한글1961이나 개역개정1998로 바꾸거나 대한성서공회의 공식 제공 앱이라고 표시하지 않는다. 역사적 판본의 동일성을 독립 감정했다고 주장하지 않는다.

[eBible Public Domain 안내](https://ebible.org/publicdomain.htm)는 해당 공개 영역 본문의 복제·배포·앱 편입·변형·상업 판매 등을 허용한다고 설명한다. 이 특정 자료의 공개 영역 표시와 일반 안내를 함께 근거로, 광고가 있는 무료 앱에서 이 본문을 표시하고 정확한 출처와 함께 공유하는 재사용 근거를 확보했다. 앱 자체의 광고 정책 승인과 전 세계 모든 관할의 법률 판정을 의미하지는 않는다. 본문 자체에 독점 저작권을 주장하지 않는다.

[대한성서공회 개역한글 FAQ](https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=5)는 개역한글의 저작재산권 기간 경과와 성명표시·동일성 유지 요구를 안내한다. [공식 저작권 표](https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_4_1)는 개역한글판의 재산권 종료일을2011-12-31로 적고 있다. 이것이 다른 역본·웹사이트 해설·사진·녹음·플랫폼 자료 전체의 무료 이용 근거는 아니다. 이번 앱은 별도로 제공자가 공개 영역이라고 표시한 eBible 자료만 사용한다.

## 낭독·공유·묵상 구분

공유할 때 본문·성경 구절·정확한 번역 표기와 출처를 유지한다. 길이를 줄여야 한다면 본문을 임의 축약하지 않고 알림에서 참조만 보여주고 앱에서 전체 절을 읽도록 한다. 생성 이미지·외부 사진·유료 폰트·녹음 성경은 이 본문 권리에 포함되지 않는다.

eBible의 낭독·각색 허용은 본문을 TTS로 읽는 데 참고할 권리 근거다. Android TTS 엔진·선택 음성·외부 음원 자체의 조건까지 확인한 것은 아니다. 녹음된 성경 음원을 가져오지 않았으며 음성 서비스 조건은 출시 담당자가 별도로 점검한다.

묵상·기도문은 이번 팩에 포함하지 않았다. 향후 AI 초안을 추가하면 `AI초안/미검수`와 사람 검수·승인 상태를 분리하고, 승인되기 전에는 사용자 화면에 성경 해설처럼 공개하지 않는다. 성경 본문과 묵상을 같은 필드에 넣지 않는다. 질병 치료·재산 증가·가족 문제 해결을 보장하거나 목회자 자격·상담 경험을 꾸미지 않는다. 본문을 광고 클릭 유도나 보상 조건으로 쓰지 않는다.

## 원천 한계와 검증 파일

다운로드한 VPL에는 베드로전서5:7이 없고4:14 다음에 베드로후서1:1이 나온다. 누락분을 모델 기억으로 채우지 않았으며 해당 절은 선정에서 제외했다. 이30개 선정 구절은 모두 별도 HTML 대조에 통과했지만 전체 성경의 완전성은 주장하지 않는다. 가독성이 불편하다고 본문을 쉬운말로 재번역하여 같은 역본으로 표시하지 않는다.

`verses.json`은 앱용 원본이다. 앱 빌드에서는 이 파일을 `app/src/main/assets/verses.json`에 동기화하고 두 파일의 SHA256이 같게 유지한다. `source-manifest.json`은 배포 ZIP·본문 파일·각 절·장HTML·권리 페이지의 해시와 URL을 남긴다. `release-gates.json`의 `contentReady`는 선정 본문 준비 완료이며 실제 스토어 출시나 광고 게재 승인과 다르다. 실제 기기 가독성·알림·공유·TTS와 광고·개인정보·스토어 준비는 출시 담당자의 결과를 따른다.
