오늘의 성경말씀 개인정보 삭제 요청 방법과 보관 기간 보기

1. 기기에 저장하는 정보

회원가입, 이름·인사말 입력, 기도문 입력, 위치·연락처·사진첩 접근 기능은 없습니다. 즐겨찾기 구절의 식별자, 글씨 크기, 알림 켜짐 여부와 선택 시각을 앱의 기기 저장소에 보관합니다. 별도 운영 서버로 동기화하지 않으며 Android 앱 백업은 꺼져 있습니다.

성경 본문 30개는 앱에 포함되어 있습니다. 읽기와 즐겨찾기는 인터넷 연결 없이 사용할 수 있습니다. 즐겨찾기를 다시 누르면 해당 저장을 해제할 수 있고, Android 설정에서 앱 데이터 삭제 또는 앱 제거를 하면 앱이 보관한 설정·즐겨찾기를 삭제할 수 있습니다.

2. Google 광고·동의 SDK

Google Mobile Ads SDK와 Google User Messaging Platform(UMP)을 사용합니다. 별도의 앱 사용 분석 SDK나 크래시 분석 SDK는 설치하지 않았습니다. 다만 광고·동의 SDK 자체의 데이터 처리는 별도로 발생할 수 있습니다.

Google의 SDK 안내에 따라 IP 주소와 이를 통한 대략적 위치, 기기·광고 식별자, 광고와 앱의 상호작용, 진단·성능 정보 등이 광고 제공, 측정, 부정 이용 방지 등을 위해 Google에 수집·공유될 수 있습니다. 전송은 SDK가 사용하는 TLS 보호를 따릅니다. 세부 처리·보관·삭제는 Google 정책과 기기 설정의 영향을 받습니다.

앱은 npa=1로 비맞춤 광고를 요청하지만, 이것이 데이터 수집이나 기기 식별자 처리가 전혀 없다는 뜻은 아닙니다. UMP가 제공하는 동의 절차와 광고 요청 가능 상태를 확인한 뒤 광고를 요청하며, 필요한 경우 설정의 ‘광고 개인정보 선택’에서 선택 양식을 다시 열 수 있습니다. 광고·동의 처리에 실패하면 광고 영역을 숨기며 말씀 기능은 계속 사용할 수 있습니다.

성경 본문, 즐겨찾기 내용, 기도 내용, 종교적 관심 분류를 광고 요청 매개변수에 넣지 않습니다. 종교 기반 맞춤 광고를 위한 키워드나 콘텐츠 URL도 전달하지 않습니다.

  • Google Mobile Ads SDK 데이터 공개 안내
  • Google 개인정보처리방침
  • Google 광고 기술 안내

3. 알림과 소리로 듣기

알림은 Android 기기의 로컬 예약 기능을 사용합니다. 알림 권한은 선택 사항이며 거절해도 말씀 읽기를 사용할 수 있습니다. 기기 재시작이나 시간 변경 후 예약을 다시 설정하기 위해 시스템 알림을 받을 수 있습니다. 별도 푸시 서버는 사용하지 않습니다.

소리로 듣기는 기기에 이미 설치되어 있고 네트워크 연결이 필요 없다고 표시된 한국어 TTS 음성을 선택합니다. 해당 음성이 없으면 재생하지 않고 기기의 음성 설정으로 안내합니다. 앱이 자동으로 음성을 다운로드하지 않습니다. 사용자가 OS 설정에서 음성을 설치하거나 변경하는 과정에는 해당 음성 제공자의 네트워크 통신과 정책이 적용될 수 있습니다.

4. 말씀 카드 공유와 임시 파일

사용자가 공유를 누르면 본문·구절·출처가 포함된 PNG 이미지를 앱 캐시에 생성합니다. 사용자가 선택한 다른 앱에 그 이미지의 임시 읽기 권한을 전달합니다. 다른 앱과 받는 사람이 보관한 사본에는 해당 서비스의 정책이 적용되며, 이 앱에서 사본을 회수하거나 삭제할 수 없습니다.

생성 후 24시간이 지난 캐시 이미지는 다음 카드 공유를 할 때 정리합니다. 정확히 24시간 후 자동 삭제되는 방식은 아닙니다. Android 설정의 앱 캐시 삭제 또는 앱 제거로 앱의 캐시를 정리할 수 있습니다.

5. 개인정보 삭제 요청 방법

오늘의 성경말씀 · BaroLab의 개인정보 삭제를 요청하는 방법입니다. 앱에 가입 계정과 별도 서버 동기화 기능은 없습니다. 기기 안의 데이터는 아래 방법으로 직접 삭제할 수 있고, 운영자가 보유한 문의 메일은 이메일로 삭제를 요청할 수 있습니다.

이메일로 요청하는 단계

  1. 메일로 개인정보 삭제 요청하기를 누르거나 baro76650@gmail.com으로 메일을 보내 주세요.
  2. 메일 제목은 오늘의 성경말씀 개인정보 삭제 요청으로 적어 주세요.
  3. 삭제를 원하는 대상을 설명해 주세요. 예를 들어 운영자에게 보낸 문의 메일이라면 보낸 시기·제목·발신 주소처럼 대상을 찾는 데 필요한 최소한의 내용을 적어 주세요. 비밀번호·주민등록번호·불필요한 신앙 상담·건강 정보는 보내지 마세요.
  4. 운영자가 확인 가능한 대상과 처리 범위를 확인한 뒤 회신합니다. 운영자가 보유한 문의 메일은 삭제 요청 대상에 포함됩니다. 직접 삭제할 수 없는 제3자 기록이라면 해당 제공자의 절차를 안내하며, 모든 기록의 일괄 삭제를 보장하지 않습니다.

삭제하거나 보관하는 데이터와 기간

  • 즐겨찾기·알림·글씨 크기 설정: 사용자가 변경·삭제하거나 앱 데이터를 삭제할 때까지 해당 기기에 보관됩니다. Android의 ‘설정 → 앱 → 오늘의 성경말씀 → 저장공간 → 데이터 삭제’ 또는 앱 제거로 삭제할 수 있습니다. 메뉴 이름은 기기마다 다를 수 있습니다. 즐겨찾기 한 개는 앱에서 해당 저장을 다시 눌러 해제할 수 있습니다. 운영자는 이 기기 데이터를 원격으로 조회·삭제하지 않습니다.
  • 공유 카드 임시 PNG: 생성 후 24시간이 지난 파일은 다음 카드 공유 때 정리합니다. 정확히 24시간 후 자동 삭제되는 방식은 아니며, 다음 공유 전까지 남아 있을 수 있습니다. Android 앱 캐시 삭제 또는 앱 제거로 정리할 수 있습니다.
  • 운영자에게 보낸 문의 메일: 이메일 주소와 문의 내용은 답변 및 후속 처리에 필요한 동안 메일 서비스에 보관됩니다. 이 메일도 삭제를 요청할 수 있습니다. 삭제 요청 자체의 메일은 대상 확인과 처리 결과 회신에 필요한 동안 사용하며, 확인 결과와 가능한 삭제 범위를 회신합니다. 별도의 앱 회원 정보나 즐겨찾기를 운영 서버에 보관하지 않습니다.
  • Google 광고·동의 SDK의 기록: Google의 처리 목적·보관 정책과 기기 설정에 따릅니다. 앱 제거가 Google 보유 기록의 삭제를 뜻하지 않으며, 운영자는 이 기록에 대해 고정된 삭제 시점이나 일괄 삭제를 보장할 수 없습니다. 관련 선택과 요청은 Google 개인정보처리방침의 정보 관리·삭제 절차 및 Android 광고 개인정보 설정을 확인해 주세요.
  • 다른 앱이나 받는 사람이 보관한 공유 사본: 해당 서비스와 받는 사람의 보관·삭제 방식에 따릅니다. 이 앱의 캐시 삭제와 별개이며 운영자가 사본을 회수하거나 일괄 삭제할 수 없습니다.

이 페이지는 삭제 요청의 접수 경로와 확인 가능한 처리 범위를 안내합니다. 자동 계정 삭제나 새로운 자동 삭제 기능을 제공하는 것은 아닙니다. 추가 개인정보 문의도 위 이메일로 보내실 수 있습니다.
