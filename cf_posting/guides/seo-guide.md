# CF 구글·빙 검색 독자를 위한 편집 기준

목표는 지속적인 질문, 새롭게 생긴 문제, 앞으로 생길 궁금증을 찾아 독자가 목적을 달성하는 글을 만드는 것이다. 아래는 이 프로젝트의 편집 기준이며 검색엔진의 고정 랭킹 공식이나 순위·수익 보장이 아니다. 네이버 C-Rank·DIA나 스마트에디터 전용 규칙을 CF 웹사이트의 합격 기준으로 사용하지 않는다.

## 검색 의도와 실제 가치

메인 키워드를 자연스럽게 포함한 제목에서 해결 범위를 약속하고 본문에서 그 약속을 마친다. 짧은 답, 필요한 조건, 실행 또는 판단 방법, 결과 확인을 우선한다. 독자의 목적이 실행이면 따라 할 수 있는 단계와 실제 화면을, 비교이면 선택 조건과 예를, 계산이면 입력·과정·출력을 제공한다.

경쟁 글은 실제 읽은 범위에서 비교한다. 현재 확인한 UI, 부분 복구, 실패 시 다음 행동, 결과 대조 등 기존 글보다 더 해결할 질문을 본문에 구현한다. 출처 수, 분량, 사진 수, 추상적인 전문성 문구로 유용함을 대신하지 않는다. 특정 화면 구성 하나를 순위의 원인으로 단정하지 않는다.

수요 데이터는 검색엔진·수집 시각·범위를 함께 기록한다. 네이버 수치나 광고 경쟁도를 구글·빙의 검색량·콘텐츠 경쟁도와 동일시하지 않는다. 미조회·추정·실측을 구분한다. 계절이나 업데이트 이후의 질문도 다룰 수 있으나 미래의 관심을 확정된 사실처럼 쓰지 않는다.

## 웹 문서 편집

제목과 설명은 실제 본문과 맞추고, H2/H3는 독자의 질문이나 작업 순서에 맞춰 둔다. 키워드 반복·숨김 텍스트·본문과 무관한 태그는 사용하지 않는다. 이미지 대체 텍스트와 캡션은 필요한 화면의 의미를 설명한다. 모바일에서 핵심 화면과 표를 읽을 수 있게 한다.

동일 질문의 기존 글은 업데이트한다. 원래 URL과 발행 정보를 보존하고 수정일을 구분한다. 다른 질문이면 해결 결과의 차이를 명시한다. 단순 연도 변경이나 표현 변경으로 유사한 글을 늘리지 않는다.

원본 관측·사실의 정확성·기술적인 검색 접근성도 필요하지만, 독자의 문제 해결을 대체하지는 못한다. 콘텐츠 검수는 글 자체의 실행 가능성과 구체적 가치를 확인하고, 색인·노출·클릭·성과는 실제 수집 데이터로 따로 확인한다.
