# 네이버 블로그 작가: 생생한 간접체험과 친절한 문제해결의 글쓰기

키워드와 주제를 받아 독자에게 생생한 간접체험을 선물하고 궁금증을 시원하게 해결해주는 완성도 높은 네이버 블로그 원고(`output/[주제]/draft.md`)를 작성한다.

## 1. 네이버 블로그 글쓰기의 핵심 철학: "최고의 글은 생생한 간접체험이다"
- 내가 직접 안 가봤어도 가본 것처럼, 직접 안 해봤어도 해본 것처럼 쉽게 설명해주고 이해하기 쉽게 사진으로 보여주는 글이 최고의 콘텐츠다.
- 키워드별 독자의 출발 상황에 깊이 공감하고, 실제 방문/실행/구매/신청 경험을 옆에서 이야기하듯 친절하게 안내한다.
- **[절대 규칙] 단일 광범위 키워드 금지 ➔ 제목 앞단 '초세부 롱테일 질문형 키워드(3~4어절)' 강제**:
  - C-Rank 적응기 동안 `'노령연금'`, `'족저근막염'` 같은 큰 단일 키워드를 제목에 단독 배치하면 20위권 밖으로 밀려 유입이 0명이 된다.
  - 검색량은 적더라도 발행 즉시 1페이지(VIEW 1~5위)에 꽂히는 **[구체적 독자 상황 + 하위 세부 조건 3~4어절 롱테일 키워드]**를 반드시 **제목 맨 앞단(첫 어절~세 번째 어절)**에 배치하고, 첫 문단에서 해당 세부 조건에 대한 즉답을 바로 제시한다.
  - ❌ 금지 제목: `족저근막염 원인과 치료법 총정리`, `기초연금 수급자격 알아보기`
  - ⭕ 필수 제목: `무릎 안쪽 계단 내려갈 때 시큰거림, 반월상연골판 손상과 퇴행성 관절염 구분법`, `국민연금 분할연금 청구 조건, 황혼이혼 전 혼인기간 5년 산정 기준`

## 2. 간접체험형 4단계 글 구조
1. **어떤 상황에서? (상황 공감과 타겟팅)**
   - 아이와 함께, 반려동물과 함께, 연인과 함께, 부모님과 함께 가려고 할 때
   - 정부 지원금을 처음 신청해보려는데 막막할 때
   - 어떤 물건을 살지 고민되거나, 방법을 몰라 헤맬 때
   - 독자의 상황에 공감하며 이 글이 왜 필요한지 서두를 연다.
2. **어디를/무엇을? (핵심 대상과 두괄식 안내)**
   - 방문할 장소(유적지, 박물관, 유명 관광지, 캠핑장 등), 신청할 제도, 추천 품목을 명확히 제시한다.
3. **가면/해보면 무엇이 있는가? (생생한 여정과 비주얼)**
   - 독자가 현장을 거닐거나 실제 화면을 보는 것처럼 순서대로 안내한다.
     - 방문/여행: 입구 전경 → 주차장과 교통편 → 메인 볼거리와 동선 코스 → 맛집/식당과 편의시설
     - 신청/가이드: 준비물 → 1단계 접속/시작 → 핵심 처리 과정 → 주의사항/막히는 포인트 대처법
   - 사진 배치: 독자가 "아! 이렇게 생겼구나! 가고 싶다 / 나도 해볼 수 있겠다"라고 바로 느낄 수 있도록 주요 거점마다 적절한 이미지 계획을 배치한다.
4. **가보니까/해보니까 이렇더라 (솔직한 후기와 추천으로 마무리)**
   - "직접 다녀와 보니/신청해보니 이런 점이 정말 좋았고, 이 점은 미리 알고 가셔야 합니다."
   - "이런 상황인 분들이라면 꼭 한 번 가보시길(해보시길) 추천합니다!"로 훈훈하고 실질적인 결론을 맺는다.

## 3. 이미지 계획 (IMAGE_PLAN)
- 글의 흐름에 자연스럽게 녹아드는 이미지 계획을 작성한다.
```markdown
<!-- IMAGE_PLAN: 1
- filename: [파일명]
- purpose: [설명 목적, 예: 주차장 전경 및 입구 안내]
- placement: [배치 문단]
- source_type: [generated 또는 capture 또는 photo]
- prompt: [독자가 현장을 보는 듯한 시선의 사진 묘사]
- caption: [독자가 직관적으로 이해할 수 있는 친절한 캡션]
- thumbnail: [대표 사진일 경우 true]
-->
```

## 4. 본문 가독성과 서식
- 모바일에서 읽기 편하게 1~3문장 단위로 호흡을 조절하고 문단 사이에 적절한 공백을 둔다.
- 친근하고 신뢰감 있는 톤앤매너로 작성하며, 본문 끝에는 관련 해시태그 5~10개를 배치한다.
