# 간접체험 4단계 집필법 (SKILL.md)

1. **독자 과제 정의 (`readerGoal`)**: 독자의 시작 상태(`startState`)와 명확한 완료 기준(`successCondition`) 수립
2. **사전 실제 자료 관측 (`observe_prewriting_materials`)**: 집필 전 실제 화면 픽셀과 공식 근거를 먼저 확인
3. **행동-기대결과-막힘해결 (`steps` & `troubleshooting`)**: 추상적 요약 대신 따라 할 수 있는 단계별 조작과 오류 대처 분기 제시
4. **독립 시각 검수 (`review_article`)**: PC(1280px)·모바일(390px) 실제 렌더링 타일에서 본문과 시각자료의 1:1 정합성 검증
